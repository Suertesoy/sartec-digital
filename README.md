# Sartec Digital

Landing page institucional da **Sartec Digital** — frente de soluções digitais da Sartec.

## Sobre

A Sartec Digital oferece ecossistemas digitais completos para pequenos e médios negócios, com foco em:

- Automação de atendimento via WhatsApp
- Landing pages de alta conversão
- Aplicativos web e mobile
- CRM inteligente
- Consultoria e estratégia digital

## Tecnologias

HTML5 · CSS3 · JavaScript puro (sem frameworks ou dependências)

## Deploy

Hospedado na **Vercel** com configuração estática:

| Parâmetro        | Valor   |
|------------------|---------|
| Application Preset | Other |
| Root Directory   | `./`    |
| Build Command    | _(vazio)_ |
| Output Directory | `.`     |
